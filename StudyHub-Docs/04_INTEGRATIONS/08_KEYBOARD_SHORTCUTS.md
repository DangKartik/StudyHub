# 1. Purpose

Keyboard shortcut integration provides fast navigation and efficient workflows for power users.

StudyHub is designed for students who use:

```
Mac

iPad with Keyboard

External Keyboards

Trackpad
```

---

# 2. Shortcut Philosophy

Keyboard shortcuts should:

- Reduce repetitive actions.
- Improve productivity.
- Support advanced users.
- Maintain consistency with Apple applications.

---

Traditional workflow:

```
Click Navigation

↓

Find Feature

↓

Perform Action
```

StudyHub workflow:

```
Keyboard Shortcut

↓

Instant Action
```
