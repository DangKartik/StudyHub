# 1. Purpose

This document defines the official terminology used throughout StudyHub.

The goal is to maintain:

```
Consistent Language

Clear Communication

Better User Experience

Easier Development
```

---

# 2. Terminology Principles

StudyHub terminology should be:

```
Simple

Student-Friendly

Consistent

Understandable
```

---

# 3. Core Product Terms

---

# StudyHub

Definition:

The complete academic productivity and learning platform.

Used for:

```
Course Management

Learning Tools

Study Planning

Knowledge Organization
```

---

# Student

Definition:

The primary user of StudyHub.

A student uses StudyHub to:

```
Organize Academic Work

Study Effectively

Track Progress
```

---

# Academic Workspace

Definition:

The central environment containing all academic information.

Includes:

```
Semesters

Courses

Lectures

Assignments

Resources
```

---

# 4. Academic Structure Terms

---

# Semester

Definition:

A specific academic period containing courses and learning activities.

Example:

```
Semester 1

Semester 2
```

---

# Course

Definition:

A subject or academic module taken by a student.

Examples:

```
Data Structures

Machine Learning

Mathematics
```

---

# Course Dashboard

Definition:

The central page for a course.

Contains:

```
Progress

Lectures

Assignments

Resources

Statistics
```

---

# Lecture

Definition:

A learning session or academic content unit inside a course.

Can contain:

```
Notes

Materials

Recordings

Readings
```

---

# Lecture Note

Definition:

User-created or imported academic notes associated with a lecture.

---

# Reading

Definition:

Additional learning material.

Examples:

```
Books

Research Papers

Articles

Documentation
```

---

# Resource

Definition:

Any supporting material related to learning.

Examples:

```
PDFs

Links

Files

Videos
```

---

# Assignment

Definition:

An academic task requiring completion.

Contains:

```
Deadline

Description

Status

Priority
```

---

# Deadline

Definition:

The date and time by which an academic task should be completed.

---

# 5. Learning Terms

---

# Flashcard

Definition:

A question-answer learning unit used for memory practice.

Structure:

```
Front

↓

Question


Back

↓

Answer
```

---

# Flashcard Deck

Definition:

A collection of related flashcards.

Example:

```
Machine Learning Concepts Deck
```

---

# Active Recall

Definition:

A learning technique where users retrieve information from memory instead of passively reviewing.

Example:

```
Question

↓

Recall Answer

↓

Check Understanding
```

---

# Spaced Repetition

Definition:

A learning method that schedules reviews at optimized intervals.

Goal:

```
Long-Term Memory Retention
```

---

# Review Session

Definition:

A study session where users practice flashcards or concepts.

---

# Study Session

Definition:

A focused period of learning activity.

Contains:

```
Duration

Activity

Progress

Statistics
```

---

# Study Mode

Definition:

A focused environment designed to help students concentrate.

Includes:

```
Timer

Focus Tools

Distraction Reduction
```

---

# Pomodoro Session

Definition:

A timed study interval based on focused work periods and breaks.

---

# 6. Organization Terms

---

# Dashboard

Definition:

The main overview screen showing important information.

Contains:

```
Upcoming Tasks

Progress

Quick Actions

Statistics
```

---

# Sidebar

Definition:

Navigation panel providing access to major sections.

---

# Widget

Definition:

A compact view displaying important information outside the main application.

Examples:

```
Upcoming Deadline Widget

Study Progress Widget
```

---

# Search

Definition:

A system for finding information across StudyHub.

Searches:

```
Courses

Notes

Flashcards

Resources
```

---

# Filter

Definition:

A tool for narrowing displayed information.

Example:

```
Show Only Completed Tasks
```

---

# Sort

Definition:

A method of arranging information.

Example:

```
Sort By Deadline
```

---

# 7. Progress Terms

---

# Progress

Definition:

A measurement of completion or advancement.

Examples:

```
Course Completion

Assignment Completion

Study Progress
```

---

# Completion Rate

Definition:

The percentage of completed items compared to total items.

---

# Learning Analytics

Definition:

Data showing learning behavior and performance.

Examples:

```
Study Time

Review History

Progress Trends
```

---

# Statistics

Definition:

Numerical insights about user activity.

Examples:

```
Hours Studied

Cards Reviewed

Tasks Completed
```

---

# 8. AI Terms

---

# AI Assistant

Definition:

An intelligent assistant that helps users learn and organize academic information.

Capabilities:

```
Explain Concepts

Summarize Notes

Generate Questions

Create Study Plans
```

---

# AI Tutor

Definition:

A personalized AI system designed to explain concepts and support learning.

---

# AI Study Plan

Definition:

A personalized schedule generated using academic goals and learning data.

---

# AI Context

Definition:

The information provided to AI to generate relevant responses.

Examples:

```
Course Content

Notes

Learning History
```

# 9. Technical Terms

---

# App Shell

Definition:

The structural foundation of the application.

Contains:

```
Navigation

Global Layout

Shared Components
```

---

# Component

Definition:

A reusable UI element.

Examples:

```
Button

Card

Navigation Bar
```

---

# Design System

Definition:

A collection of reusable design rules and components.

Includes:

```
Colors

Typography

Spacing

Components
```

---

# View

Definition:

A user interface screen or UI component.

Example:

```
CourseView

DashboardView
```

---

# ViewModel

Definition:

A layer responsible for managing UI state and business logic.

Architecture:

```
View

↓

ViewModel

↓

Service
```

---

# Service

Definition:

A system component responsible for external operations.

Examples:

```
Database Service

Calendar Service

AI Service
```

---

# Model

Definition:

A representation of application data.

Examples:

```
Course Model

Assignment Model
```

---

# 10. Data Terms

---

# Local Storage

Definition:

Data stored directly on the user's device.

Examples:

```
Courses

Notes

Settings
```

---

# Cloud Sync

Definition:

Synchronization of user data across devices.

Example:

```
iPhone

↓

iPad

↓

Mac
```

---

# Backup

Definition:

A copy of user data used for recovery.

---

# Migration

Definition:

The process of updating stored data when the application structure changes.

# 11. User Experience Terms

---

# Empty State

Definition:

A screen shown when no data exists.

Example:

```
No Courses Yet

Create Your First Course
```

---

# Loading State

Definition:

The UI shown while information is being prepared.

Examples:

```
Spinner

Skeleton View
```

---

# Error State

Definition:

A UI state explaining when something fails.

---

# Feedback

Definition:

A response from the application after user action.

Examples:

```
Haptic Feedback

Animation

Message
```

---

# 12. Status Terms

---

# Active

Definition:

Currently being used or available.

---

# Completed

Definition:

Successfully finished.

---

# Pending

Definition:

Waiting for completion or action.

---

# Archived

Definition:

Stored but no longer actively displayed.

---

# Deleted

Definition:

Removed from active use.

---

# 13. Official Naming Rules

Use:

```
Course

Not Subject


Assignment

Not Homework


Flashcard

Not Card


Study Session

Not Session
```

---

# 14. Avoided Terms

Avoid confusing terminology.

Do not use:

```
Thing

Item

Stuff

Data Object
```

in user-facing interfaces.
