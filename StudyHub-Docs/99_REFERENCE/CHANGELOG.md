# 1. Purpose

This document records all major changes, improvements, fixes, and releases made to StudyHub.

The changelog provides:

```
Release History

# 2. Changelog Format

```

# 3. Versioning Convention

StudyHub follows:

```
MAJOR.MINOR.PATCH
```

Example:

```
2.1.3
```

Meaning:

```
2

Major Release


1

Feature Update


3

Bug Fix Release
```
